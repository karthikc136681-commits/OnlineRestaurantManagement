
# Online Restaurant Management and Food Ordering System

## Project Overview
The Online Restaurant Management and Food Ordering System is a web-based application developed to simplify restaurant management and online food ordering.

Customers can register, log in, browse food items, add items to their cart and place orders. The application also provides separate interfaces for administrators and delivery personnel.

## Technologies Used
- Java (JDK 21)
- JSP (JavaServer Pages)
- Java Servlets
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat
- NetBeans IDE
- XAMPP and phpMyAdmin

## Main Modules
- Customer Registration and Login
- Food Menu
- Shopping Cart
- Food Ordering
- Admin Dashboard
- Food and Category Management
- User Management
- Order Management
- Delivery Dashboard

## Database
Database Name: `restaurant_db`

The database contains tables for users, customers, admins, categories, food items, cart, cart items, restaurant orders, order items and payments.

## Development Environment
- IDE: NetBeans
- Java Version: JDK 21
- Database: MySQL
- Server: Apache Tomcat
